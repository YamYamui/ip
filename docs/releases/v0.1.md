# King v0.1

Download **King.jar** from the release assets. Java 25 is required.

Copy the JAR into an empty folder, open a terminal there, and run:

```text
java -jar "King.jar"
```

Supported commands: `todo`, `deadline`, `event`, `list`, `mark`, `unmark`,
`delete`, and `bye`. King explains invalid commands and keeps running.

Tasks are saved automatically to `data/king.txt` beside the JAR and restored
at startup. Missing folders are created automatically. Keep the data folder
when upgrading. If a save is corrupt or unreadable, King reports the problem
and stops startup without overwriting it.

This release includes Level-7 saving, Level-6 deletion, A-Collections,
A-Packages, and the A-Jar executable distribution.
